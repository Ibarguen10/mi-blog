Construí una app de lista de tareas con JavaScript vanilla — sin frameworks

Mi primer proyecto "real". Quería entender el DOM antes de saltar a React.

¿Por qué este proyecto?

Llevaba semanas aprendiendo JavaScript con tutoriales y ejercicios, pero sentía que no había construido nada real. Decidí hacer una app de tareas — simple, clásica, pero mía.

La regla que me puse: nada de frameworks, nada de librerías. Solo HTML, CSS y JavaScript puro.

Lo que aprendí

Este proyecto me enseñó tres cosas que ningún tutorial me había dejado claro:

  • Cómo manipular el DOM con querySelector y createElement
  • Cómo escuchar eventos con addEventListener
  • Cómo guardar datos en localStorage para que no se pierdan al recargar

El código

La función más importante del proyecto fue saveTasks() — guarda las tareas en el navegador:

js/main.js 
// Guardar tareas en localStorage
function saveTasks(tasks) {
  localStorage.setItem('tasks', JSON.stringify(tasks));
}

// Cargar tareas al iniciar
function loadTasks() {
  const saved = localStorage.getItem('tasks');
  return saved ? JSON.parse(saved) : [];
}

// Agregar nueva tarea
function addTask(text) {
  const tasks = loadTasks();
  tasks.push({ id: Date.now(), text, done: false });
  saveTasks(tasks);
  renderTasks();
}

El error que más me costó

Estuve 2 horas confundido porque mis tareas desaparecían al recargar la página. El problema era que estaba guardando el array directamente:

❌ Incorrecto 
localStorage.setItem('tasks', tasks); // guarda "[object Object]"
✅ Correcto 
localStorage.setItem('tasks', JSON.stringify(tasks)); // guarda el JSON real

Esa diferencia entre un objeto y su representación en texto me enseñó más sobre JavaScript que cualquier tutorial.

Próximo paso

Quiero agregar categorías a las tareas y un filtro por estado. También voy a intentar reescribirlo con React para ver qué tan diferente es el proceso.
