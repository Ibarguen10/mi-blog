Formatear fechas sin librerías JavaScript

Convierte un objeto Date a formato legible en español sin usar moment.js ni date-fns.

function formatDate(date) {
  return new Date(date).toLocaleDateString('es-CO', {
    year: 'numeric',
    month: 'long',
    day: 'numeric'
  });
}

// Uso:
formatDate('2026-03-15'); // "15 de marzo de 2026"
Debounce para inputs JavaScript

Evita que una función se ejecute demasiado rápido — útil para búsquedas en tiempo real.

function debounce(fn, delay) {
  let timer;
  return function(...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}

// Uso:
const buscar = debounce((q) => console.log(q), 300);
input.addEventListener('input', e => buscar(e.target.value));
Guardar y leer localStorage JavaScript

Wrapper simple para guardar y leer objetos en localStorage sin acordarse del JSON.

const storage = {
  set(key, value) {
    localStorage.setItem(key, JSON.stringify(value));
  },
  get(key) {
    const item = localStorage.getItem(key);
    return item ? JSON.parse(item) : null;
  },
  remove(key) {
    localStorage.removeItem(key);
  }
};

// Uso:
storage.set('usuario', { nombre: 'Cristian' });
storage.get('usuario'); // { nombre: 'Cristian' }
Centrar con flexbox CSS

La forma más rápida de centrar cualquier elemento horizontal y verticalmente.

.centrado {
  display: flex;
  align-items: center;
  justify-content: center;
}

/* Centrar en toda la pantalla */
.pantalla-completa {
  display: flex;
  align-items: center;
  justify-content: center;
  min-height: 100vh;
}
Truncar texto con puntos suspensivos CSS

Corta el texto que no cabe en una línea y agrega "..." al final automáticamente.

/* Una línea */
.truncar {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

/* Múltiples líneas (ej: 3) */
.truncar-3 {
  display: -webkit-box;
  -webkit-line-clamp: 3;
  -webkit-box-orient: vertical;
  overflow: hidden;
}
